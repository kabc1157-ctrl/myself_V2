## 2026-11-20 성향 검사 P2 — 35문항 채점 엔진

- 사용자 승인된 35문항 수는 유지하면서 문항 분포를 **Big Five 20 / 동기 6 / 실행 9**로 조정함. 10개 영역 모두 최소 3문항(영역별 4/3/3개).
- 질문 35개와 역채점 후보를 `src/core/personality/questions.ts`에 버전 `ieumsae-35-provisional-v2`로 고정. 기존 V2 원격 DB의 평가 응답이 0건임을 확인하고 변경.
- 채점 엔진: `src/core/personality/scoring.ts`. 5점 척도 1~5를 정방향 그대로, 역방향은 `6 - 응답`으로 변환한 후 영역 평균을 `Math.round((평균 - 1) * 25)`로 0~100점 환산.
- 내부 설명 구간: 0~39 낮음, 40~69 혼합, 70~100 높음. 백분위/비교/임상진단이 아닌 임시 해석 규칙.
- 모든 35개 문항이 올바르게 입력되어야 점수 계산 가능. 누락, 추가 ID, 문자열 외 응답, 1~5 범위 초과는 오류 처리. 초안 저장은 정상적인 부분 응답만 수용.
- 향상초점과 예방초점은 독립적으로 계산. 상반된 응답 탐색을 위해 영역별 응답 분산폭도 함께 반환.
- Vitest 단위 테스트 10종 이상 작성(중립값, 양극단, 역채점, 평균 반올림, 독립성, 구간 경계, 불완전/조작 입력, 초안, 원본 불변).
- 정적 소스 검사에서 질문 35개, 영역 10개, 영역별 최소 3개, 역채점 15개 및 채점식과 테스트 파일 존재 확인.
- GitHub 연결 파일만 직접 수정 가능했고 테스트 실행 컨테이너에서 GitHub DNS 접속이 불가해 lint/typecheck/Vitest/build는 **미실행**, 로그인 브라우저 검증 역시 미실행.
- 점수 계산 함수를 프로덕션 제출/DB 저장/결과 UI에 아직 연결하지 않음. P3 리포트 규칙 및 최종 제출 트랜잭션이 완성되기 전 결과를 확정·공개하지 않음.
